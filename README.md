# Ciência de Dados e Analytics — PUC-Rio

Este repositório reúne os projetos desenvolvidos no âmbito da formação em **Ciência de Dados e Analytics da PUC-Rio**, organizados de acordo com os diferentes módulos e eixos de aprendizagem do curso.

Os projetos aqui apresentados procuram articular os conhecimentos desenvolvidos ao longo da formação com problemas concretos de pesquisa e análise de dados, abrangendo etapas relacionadas à engenharia, organização, tratamento, análise e modelagem de dados. Sempre que possível, os trabalhos são estruturados a partir de bases de dados reais e orientados para a construção de produtos analíticos reproduzíveis.

O repositório está organizado em três áreas principais:

## Projetos

### Engenharia de Dados

Projeto dedicado à construção de uma arquitetura de dados para análise do trabalho por plataformas digitais no Brasil, utilizando microdados da **Pesquisa Nacional por Amostra de Domicílios Contínua (PNAD Contínua)**.

O projeto contempla a ingestão, transformação, modelagem e disponibilização dos dados por meio de uma arquitetura em camadas **Bronze, Silver e Gold**, além da construção de tabelas analíticas e controles de qualidade.

➡️ [Acessar o projeto de Engenharia de Dados](ciencia_dados_analytics/engenharia_dados/)

### Análise de Dados e Boas Práticas

Espaço destinado ao projeto desenvolvido no módulo de **Análise de Dados e Boas Práticas**, contemplando a exploração, tratamento, análise e comunicação de dados a partir dos conteúdos trabalhados ao longo da disciplina.

*Projeto em desenvolvimento.*

### Machine Learning e Analytics

Espaço destinado ao projeto desenvolvido no módulo de **Machine Learning e Analytics**, voltado à aplicação de técnicas de modelagem e aprendizagem de máquina a problemas de análise de dados.

*Projeto em desenvolvimento.*

## Organização do repositório

Cada projeto possui seu próprio `README.md`, no qual são apresentados seus objetivos, bases de dados, procedimentos metodológicos, etapas de implementação, resultados e demais elementos necessários à documentação e reprodução do trabalho.

A estrutura será atualizada progressivamente à medida que novos projetos forem desenvolvidos ao longo da formação.
